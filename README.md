# 幸运抽奖

一个基于 Python + Tkinter 的桌面抽奖软件：从 Excel 导入或手动输入抽奖名单，奖项设置也可从 Excel 导入；按奖项等级设置获奖人数与奖品，滚动抽奖并导出中奖结果。

## 功能

- 从 `.xlsx` / `.xlsm` 文件导入名单，可选择工作表和姓名列，自动识别“姓名/name”等表头
- 支持手动输入名单，可逐个添加抽奖人、批量粘贴、删除或清空；编号自动生成
- 支持从 Excel 导入奖项设置（奖项名称、奖品、获奖人数）
- 自由添加、编辑、删除奖项等级，设置每个奖项的获奖人数和奖品
- 默认从最低奖项开始抽奖，抽满后自动切换到更高奖项
- 每次可选择抽取 1 人，或一次抽满该奖项的全部剩余名额
- 滚动动画抽奖，**每人最多中奖一次**；同名人员按不同参与者处理
- 自动为每位参与者分配 1–N 编号，同名的抽奖者也能清楚区分
- 实时显示各奖项进度、剩余人数和中奖名单
- 一键导出中奖名单 + 奖品统计到 Excel
- 奖项配置自动保存到 `config/tiers.json`

## 环境要求

- Python 3.10+（开发验证版本：3.13）
- Tkinter（Windows 官方 Python 自带）
- openpyxl

## 安装与运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

也可以直接双击 `run.bat`。

## 打包为独立 exe

无需安装 Python 即可运行：

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name 幸运抽奖 app.py
```

生成的 `dist/幸运抽奖.exe` 可单独复制到任意目录双击运行。奖项配置保存在 exe 同目录的 `config/tiers.json`。

## 使用步骤

1. 点击 **导入名单** 从 Excel 读取，或点击 **手动输入** 直接录入名单。
2. 在左侧添加奖项，或点击 **导入奖项** 从 Excel 读取奖项设置。
3. 在右侧选择当前奖项和抽取方式（抽 1 人 / 抽满该奖项），点击 **开始抽奖**。
4. 抽完后点击 **导出结果** 保存中奖名单和奖品统计。

> 奖项列表按“高→低”排列。默认从最低奖项（列表末尾）开始，抽满后自动切换到上一项（更高奖项）。
> 抽奖开始后如需修改奖项，请先点击 **重置抽奖**。重置只会清空中奖记录，不会清空名单和奖项。

## Excel 名单格式

只需包含一列姓名即可。示例（`sample/participants.xlsx`）：

| 序号 | 姓名 | 部门 |
| --- | --- | --- |
| 1 | 张伟 | 研发部 |
| 2 | 王芳 | 市场部 |

- 程序会在前 10 行中寻找包含“姓名 / 名字 / name / 员工”等关键词的标题行，并自动选中对应列。
- 找不到标题行时，按纯数据表处理，默认使用第一列，也可手动选择其他列。
- 只支持 `.xlsx` / `.xlsm`；旧版 `.xls` 请先在 Excel 中另存为 `.xlsx`。
- 空白单元格会被忽略；重复姓名会保留为不同参与者。
- 导入后按名单顺序自动分配编号 1–N，用于区分同名人员。

示例名单和示例奖项可通过以下命令重新生成：

```powershell
python scripts/make_sample.py
```

## 从 Excel 导入奖项

点击左侧奖项面板右上角的 **导入奖项**，选择 Excel 文件和工作表即可。示例（`sample/prizes.xlsx`）：

| 奖项名称 | 奖品 | 获奖人数 |
| --- | --- | --- |
| 一等奖 | 笔记本电脑 | 1 |
| 二等奖 | 蓝牙耳机 | 2 |
| 三等奖 | 保温杯 | 3 |

- 表头需包含“奖项/等级”（如“奖项名称”）、“人数/名额”（如“获奖人数”）；“奖品”列可选，留空时默认使用奖项名称。
- 表头行可出现在前 10 行内，前面可以有标题或空行；没有表头时按列顺序读取：3 列 = 奖项、奖品、人数，2 列 = 奖项、人数。
- Excel 行顺序应保持 **高→低**（一等奖在前）。导入后按此顺序显示，抽奖时从末尾的最低奖项开始向上进行。
- 导入会替换当前全部奖项设置；已有中奖记录时需先 **重置抽奖**。
- 只支持 `.xlsx` / `.xlsm`。

## 抽奖顺序与方式

- 默认选中最低奖项；某奖项抽满后，自动切换到上一个尚未抽满的更高奖项。
- **抽 1 人**：每次抽取一位获奖者。
- **抽满该奖项**：一次抽出该奖项剩余的全部名额；若名单人数不足，则抽出所有剩余人员并提示“名单不足”。
- 两种方式的舞台显示格式一致：每位获奖者显示为「编号 号 · 姓名」；批量抽取最多展示前 3 位，完整名单见下方中奖列表。

## 手动输入名单

点击工具栏的 **手动输入** 打开名单编辑窗口，窗口会自动载入当前名单：

- 在输入框中输入姓名，点击 **添加抽奖人**（或按回车）即可逐个添加；
- 也可以把姓名批量粘贴到下方文本框，点击 **批量添加**；
- 批量输入支持每行一个姓名，也支持英文/中文逗号、英文/中文分号、顿号或 Tab 分隔；
- 姓名内部的空格会保留（例如 `John Doe`），空行和首尾空白会被忽略；
- 可在名单中多选后 **删除选中**，或点击 **清空名单** 重新录入；
- 编号按列表顺序自动生成 1–N，重复姓名会保留为不同参与者。

点击 **确定** 后，编辑后的完整名单生效。如果已有中奖记录，会先提示并清空抽奖结果。

## 运行测试

测试使用 Python 标准库 `unittest`，无需安装 pytest：

```powershell
python -m unittest discover -s tests -v
```

运行单个测试：

```powershell
python -m unittest tests.test_engine.TestLotteryEngine.test_tier_capacity_enforced -v
```

Windows 控制台如果中文输出乱码，可先执行 `$env:PYTHONUTF8=1`。

## 项目结构

```
app.py                 程序入口
lottery/
  models.py            奖项、参与者、中奖记录数据类
  engine.py            纯逻辑抽奖引擎（无界面依赖，单元测试覆盖）
  excel_io.py          Excel 名单读取与结果导出
  tier_io.py           奖项设置 Excel 导入
  names.py             手动输入名单的解析
  config.py            奖项配置读写（config/tiers.json）
  ui.py                Tkinter 界面与交互
scripts/make_sample.py 生成示例名单与奖项
tests/                 引擎与 Excel 读写测试
sample/participants.xlsx 示例名单（40 人）
sample/prizes.xlsx     示例奖项设置
```

## 说明

- 窗口可自由缩放（最小 960×640）；窗口变小时会优先压缩舞台和列表，抽奖按钮与中奖名单始终可见，中奖姓名会自动缩放以完整显示。
- 中奖名单只保存在当前运行会话中；关闭程序前请及时 **导出结果**。
- `config/tiers.json` 是本地配置，已在 `.gitignore` 中忽略；删除后会恢复默认奖项（一等奖 1 人、二等奖 2 人、三等奖 3 人）。
